# 🌐 Developer Portfolio | Onkar Shelke

A responsive, high-performance personal portfolio website built to showcase engineering projects, technical skill set, computer science visualizers, and contact details.

🔗 **Live Demo:** [https://onkarshelke110.netlify.app/](https://onkarshelke110.netlify.app/)

---

## 📌 Overview

This repository contains the source code for my personal portfolio. It presents a clear overview of my background in Computer Engineering, core competencies in software development and algorithms, showcase of web applications, and direct channels to get in touch.

---

## ✨ Features

- 📱 **Fully Responsive Layout:** Optimized for all screen resolutions (Desktop, Tablet, and Mobile).
- ⚡ **Fast Performance:** Lightweight structure for minimal load times.
- 🎨 **Modern UI/UX:** Clean typography, smooth scrolling, and intuitive navigational flow.
- 🛠️ **Project Showcase:** Highlights key projects with live demo links and technical descriptions.
- 📬 **Contact Section:** Direct reach-out links and social integrations.
